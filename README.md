## 🏆 Featured Project

<a href="https://github.com/batmandevx/Packet_analyzer">
  <img align="center" src="https://github-readme-stats.vercel.app/api/pin/?username=batmandevx&repo=Packet_analyzer&theme=radical&border_color=7F3FBF&bg_color=0D1117&title_color=C9D1D9&icon_color=F8D866" />
</a>

> 🔥 **DPI Engine v2.0** — A multi-threaded Deep Packet Inspection engine written in C++17 that analyzes PCAP files, extracts SNI from TLS/HTTPS traffic, classifies applications (YouTube, TikTok, Facebook), and blocks connections based on configurable rules. Features Load Balancer → Fast Path thread architecture with consistent hashing.
