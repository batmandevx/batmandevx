## 🏆 Featured Project

<a href="https://github.com/batmandevx/Packet_analyzer">

</a>

> 🔥 **DPI Engine v2.0** — A multi-threaded Deep Packet Inspection engine written in C++17 that analyzes PCAP files, extracts SNI from TLS/HTTPS traffic, classifies applications (YouTube, TikTok, Facebook, etc.), and blocks connections based on configurable rules. Features Load Balancer → Fast Path thread architecture with consistent hashing.
